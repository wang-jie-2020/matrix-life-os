# Matrix Life OS 文档

本目录保存当前项目文档。文档只描述当前产品范围，以及支撑该范围的实现形态。

## 优先阅读

- [PRD](PRD.md)：标准产品目标。本文档定义产品应该做什么。
- [Architecture](ARCHITECTURE.md)：当前应用结构、运行区域和本地数据行为的简明地图。
- [术语表](../CONTEXT.md)：标准产品词汇。

## 命名约定

- `PRD.md`：产品需求和验收标准。
- `ARCHITECTURE.md`：当前实现结构和运行形态。
- `docs/specs/`：预留给未来具体功能或改动的规格文档；当前没有独立 SPEC。

## Agent 支持

- [Issue Tracker](agents/issue-tracker.md)：agent 技能应如何使用本仓库的 issue tracker。
- [分诊标签](agents/triage-labels.md)：面向分诊的技能使用的标签词汇。
- [领域文档](agents/domain.md)：agent 技能应如何读取领域文档。

## 历史说明

根目录的 `CHANGELOG.md` 和 `RELEASE_NOTES.md` 描述较早的 reset 前版本。它们是历史记录，不是当前产品需求，也不是当前实现指南。
